# r-sig-qa

Quality assurance and validation

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/r-sig-qa/](https://stat.ethz.ch/pipermail/r-sig-qa/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics
